ORANGE OTTER WEBSITE — PUBLISH PACKAGE

Files:
- index.html: the website homepage
- favicon.svg: the Orange Otter mark from the website header
- apple-touch-icon.png: 180x180 icon for iOS home-screen bookmarks

To publish with GitHub Pages, create a new public repository, upload these files
into the repository root, then enable Pages from Settings > Pages, deploying
from the main branch and / (root). GitHub will show the public website address
when deployment finishes.

The site currently describes Orange Otter as in development and does not claim
that a public app download or paid pricing is available.
